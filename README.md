# Dart Crash Course — Project Overview

This folder contains small Dart example files used for a crash-course-style exploration of language features and async programming.

Files
- `async.dart`: Examples demonstrating Dart async/await, Futures, and concurrency patterns.
- `extension_methods.dart`: Examples of Dart extension methods and how to extend existing types.
- `list.dart`: Examples and utilities for working with Dart `List` collections.
- `main.dart`: Minimal entry point that ties examples together or runs quick demos.
- `mixins_and_abstracts.dart`: Examples showing mixins, abstract classes, and inheritance patterns.


Quick start

1. Ensure you have the Dart SDK installed: https://dart.dev/get-dart
2. From this folder, run the main file:

```bash
dart run main.dart
```

Notes
- Each `.dart` file is standalone and intended for learning — inspect and run them individually.
- If you want, I can add brief file-level comments inside each `.dart` with usage notes.
